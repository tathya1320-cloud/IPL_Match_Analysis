# IPL Match Analysis

This project analyzes IPL (Indian Premier League) match data to provide insights on match outcomes, team performance, and toss advantage.

## Features
- Total matches played
- Team-wise wins and win percentage
- Toss advantage percentage
- Visual plots to analyze trends

## Tech Stack
- Python
- Pandas
- Matplotlib
- Jupyter Notebook / Google Colab

## How to Run
1. Open the notebook `IPL_analysis.ipynb` in **Google Colab** or **Jupyter Notebook**.
2. Run all cells to view results and plots.
